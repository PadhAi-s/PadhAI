# Supabase

This folder is empty scaffolding for now.

- `migrations/` — SQL migrations (schema, RLS policies) land here in
  **Phase 4** (database + syllabus system).
- `functions/` — one Deno Edge Function per server-side capability
  (`ask-ai`, `generate-quiz`, `solve-image`, `get-videos`,
  `process-syllabus-pdf`, etc.), added starting **Phase 5** and mostly
  filled in during **Phase 7–9**.

Requires the [Supabase CLI](https://supabase.com/docs/guides/cli) and a
Supabase project (`supabase init`, `supabase link`) once we get there.
